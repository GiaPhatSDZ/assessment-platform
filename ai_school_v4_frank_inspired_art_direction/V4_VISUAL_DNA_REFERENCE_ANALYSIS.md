# 1. What the reference gets right

The reference direction is useful because it does NOT look like a default Tailwind SaaS landing page.

Key visual traits to preserve conceptually:

1. **Editorial typography**
   - Large, elegant display serif for brand/marketing messages.
   - Calm sans-serif for UI/product data.
   - Strong contrast between narrative text and application interface.

2. **Product-first hero**
   - The visual hero is the actual product interface, not an abstract AI orb.
   - The product preview feels like a real application window embedded into the brand page.

3. **Warm, premium canvas**
   - Off-white/cream base rather than cold white or dark navy.
   - Soft atmospheric glow used sparingly.
   - Dark ink text with one distinctive accent family.

4. **Low visual noise**
   - Fewer borders.
   - Fewer badges.
   - Fewer nested cards.
   - More whitespace and stronger type hierarchy.

5. **Human-scale narrative**
   - Short sections.
   - Plain-language questions/problems.
   - Product capabilities shown as relatable situations.

6. **Large modular product moments**
   - One strong visual per section.
   - UI screenshots / interface scenes are allowed to occupy a large share of viewport.

7. **Trust without fake dashboards**
   - Product evidence is shown through real interface/state.
   - Avoid decorative KPIs that do not exist.

# 2. What NOT to copy

This is inspiration, not cloning.

Do NOT copy:
- exact Frank logo/mascot
- exact typography choices
- exact colors
- exact component geometry
- exact copy
- exact section order
- exact illustrations
- exact product screenshots

AI School must have its own identity.

# 4. Three visual modes

## BRAND MODE
Used on:
- landing
- about/how it works
- curriculum catalog entry
- parent education pages

Traits:
- expressive
- large serif headlines
- asymmetry
- product-window compositions
- atmospheric gradients
- generous spacing

## FOCUS MODE
Used on:
- lessons
- diagnostics
- practice
- re-test

Traits:
- almost no decorative motion
- sans-serif only for task UI
- maximum readability
- one task per viewport
- no marketing blocks
- no extra badges

## INSIGHT MODE
Used on:
- gap report
- mastery history
- parent view
- knowledge graph

Traits:
- strong visualization
- evidence hierarchy
- selective serif headings
- source citations visible
- explanation-first

# 5. Product signature

AI School should own one distinctive visual system:

```text
KNOWLEDGE PATH
```

A thin directional path connecting learning nodes:

```text
Foundation → Prerequisite → Target → Re-test
```

This becomes:
- landing visual motif
- curriculum navigation motif
- result/gap visual
- learning history motif

Do not scatter generic icons as the main identity.

---

# 6. Anti-slop rules

Reject any redesign that relies on:
- 3 equal feature cards under hero
- 6 equal cards with Lucide icons
- "AI-powered" glowing sphere
- purple/blue gradient backgrounds
- glassmorphism
- giant centered heading + 2 buttons + 3 badges as the only hero idea
- dark dashboard screenshot floating on black
- meaningless stats
- excessive pill labels
- every block rounded-2xl
